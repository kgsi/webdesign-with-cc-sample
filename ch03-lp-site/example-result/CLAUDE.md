# NAGARE ランディングページ 制作ルール

このディレクトリのHTMLとCSSを作成・変更するときは、ここにあるルールに従うこと。

## 色

色の変数は `css/style.css` の `:root` に定義してある。

| 変数名 | 値 | 役割 |
| --- | --- | --- |
| `--color-primary` | `#D32F2F` | 面と、24px以上の文字 |
| `--color-primary-text` | `#B71C1C` | 24px未満の文字に使う濃い赤 |
| `--color-text` | `#333333` | 本文 |
| `--color-text-muted` | `#666666` | 主役ではない文字 |
| `--color-text-on-dark` | `#FFFFFF` | 暗い地の上の文字 |
| `--color-bg` | `#FFFFFF` | 基本の地。色のついた節に置くカードの地も兼ねる |
| `--color-bg-section` | `#FFF1EB` | 節を区切るための地 |
| `--color-bg-box` | `#F5F7FA` | 白い地の上に置くボックスの地 |
| `--color-bg-dark` | `#333333` | フッター |
| `--color-accent-on-dark` | `#FFB74D` | 暗い地の上のアクセント |
| `--color-border` | `#E5E5E5` | 罫線 |
| `--color-border-on-dark` | `#555555` | 暗い地の上の罫線 |

- 色は :root の変数だけを使う。CSSに色の値を直接書かない
- 24px未満の文字に赤を使うときは --color-primary-text を使う
- 文字と地のコントラスト比は4.5:1以上。24px以上の文字は3:1以上

## 部品
- 繰り返す箱は .card にそろえる。並びは画像、見出し、本文、罫線、リンクの順
- 同じ種類に見える箱は、中の並びと余白が作るグループの切り方をそろえる
- 塗りのボタンはページの主目的の行動だけに使う。それ以外は枠線のボタン
- 暗い地に置く部品は、専用クラスを作らず .on-dark を重ねる
- .btn には border: 1px solid transparent を入れて、塗りと枠線で高さをそろえる

## アイコンと仮置き
- アイコンは描かせず、決めたセットから名前で選ぶ
- SVGはインラインで埋め込み、外部からの読み込みは使わない
- 仮置きの文字や記号を残さない。決められないものは決まるまで空欄にする

## レスポンシブ
- 切り替え点は1100pxと900pxの2つだけ。1100pxで文字の段を下げ、900pxで縦に積む
- JavaScriptは使わない
- 押せるものは44px四方以上、メニューの項目は高さ52px
- <br> を入れたら、狭い幅で1文字だけ残っていないか確かめる

## ホバー
- ホバーで変えるのは色を1段だけ。transition は0.2秒
- 文字リンクの下線に transition はつけない
- opacity でホバーを作らない
