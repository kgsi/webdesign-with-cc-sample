# 写真について

このフォルダの写真は、フリー素材サイト [ぱくたそ](https://www.pakutaso.com/) の素材です。ぱくたその利用規約で再配布が認められているSサイズ（長辺800px）の画像を同梱しています。

## 使う前に

この写真を使う前に、ぱくたその [利用規約](https://www.pakutaso.com/userpolicy.html) を読み、同意してください。このリポジトリを複製したり改変したりして使う場合も、写真には同じ規約が適用されます。

- 写真だけを取り出して、素材として再配布しないでください。素材が必要な場合は、各素材ページから取得してください
- ぱくたその素材はCC0ではありません
- サンプルサイトに登場する医院名と人物名は架空です。人物写真はイメージで、写っているモデルとは関係ありません
