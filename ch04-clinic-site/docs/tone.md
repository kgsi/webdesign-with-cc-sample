# トーン設計メモ

4-2の前提。ムードボード（`../moodboard/clinic-moodboard.html`）を言葉と数値に分解したもの。Figmaの「トーン」ページと対応する。Claude Codeへのプロンプトではこのファイルを参照させる。

## キーワード（6語）

安心と信頼、清潔感、親しみやすさ、専門性と誠実さ、地域に寄り添う、日本の医療らしさ

- 安心と信頼、専門性と誠実さ：色数を絞り、青を基調にする。装飾で盛らない
- 清潔感：白地を広く取り、罫線は淡い色で細くする。影は使わない
- 親しみやすさ：角丸を大きめに取り、ボタンは丸い形にする。写真は笑顔の人物か明るい院内
- 地域に寄り添う、日本の医療らしさ：ゴシック体の本文と、短い日本語のコピー。英語の小ラベルは控えめに添える

## 色（9色）

ムードボードのCSS変数に定義された9色。この9色以外は使わない。Tailwind標準の `gray`、`blue`、`sky` などを混ぜない。

| 名前 | HEX | 役割 |
|---|---|---|
| primary | #2F7FD0 | プライマリボタン、テキストリンク、ナビのホバー |
| primary-light | #8FC8F2 | reserve のグラデーションの終端、アクセントの面 |
| mint | #79BEA7 | 差し色。アイコンの丸、Tag の一部。面積は小さく |
| pale | #EDF6FA | セクションの淡い面、プレースホルダー、フッター背景 |
| bg | #F7FBFD | ページの薄い背景（hero、services、news） |
| line | #DBE8EF | 罫線、カードの枠 |
| white | #FFFFFF | ヘッダー、カードの面、白地のセクション |
| ink | #18364D | 見出しと本文 |
| muted | #5C7384 | キャプション、日付、補足文。2026-09-21 に #6F8697 から変更（白地で 3.8:1 だったため） |

- ムードボードのスウォッチにある `#F8FAFC` は変数に定義がないため採用しない。薄い背景は bg に統一する
- 青の面を使うのは reserve だけ。他のセクションは白と bg を交互に置く

## 書体（5段階）

Noto Sans JP（Google Fonts）。ウェイトは 400、500、700 の3つ。ムードボードのフォントスタックはOSの標準ゴシックだが、環境差をなくすため Web フォントに固定する。

| 用途 | サイズ/行送り | ウェイト |
|---|---|---|
| H1 | 40px / 60px | 700 |
| H2 | 28px / 42px | 700 |
| H3 | 20px / 32px | 500 |
| Body | 16px / 30px | 400 |
| Caption | 13px / 20px | 400 |

- 本文の行送りは広め（1.85）。ムードボードの「余白を広く取り、情報密度を抑える」に従う
- セクションの英語小ラベル（MESSAGE、SERVICES など）は Caption サイズ、字間 0.1em、大文字、muted

## 角丸と余白

- 角丸は3種類。カードと写真は 14px、小さな面（UIカード、Tag の枠）は 12px、ボタンと Tag は 999px
- 12カラム、コンテナ 1200px、左右マージン 40px、ガター 24px
- セクションの縦余白は 96px（reserve だけ 80px）。詰めない
- 罫線は 1px、line 色

## 写真の条件

- 明るく、白と淡い青が多い写真。暖色の照明や濃い影を避ける
- 人物は笑顔で、カメラに向かうか患者に向かう構図。医療機器のアップは使わない
- 出典はぱくたそ。素材ページと撮影者の一覧は `../moodboard/photo_links.md`。ぱくたその素材はCC0ではないため、画像ファイルはリポジトリに同梱せず、MサイズのURLを直接参照する

## 方向性の2案（Figma トーンページ）

| 案 | 方向性 | 採用 |
|---|---|---|
| A | 青基調。白地を広く取り、写真を大きく置く。差し色のミントはアイコンだけ | 採用 |
| B | ミント基調。淡い緑の面を増やし、写真を小さく丸く切り抜く | 不採用。小児科の印象が強くなり、内科の専門性が弱まる |

## 判断の記録

- ロゴは「さくら台内科クリニック」のテキストワードマーク。ムードボードに医院名はなく、第4章で決めた
- ムードボードの「アクセス」「よくある質問」のUIカードは、トップのセクションとナビ項目に振り分けた
- ムードボードのコピーはそのまま使う。hero の「いつもの暮らしに、あんしんを。」、message の「患者さんに寄り添う医療を、これからも」、reserve の「WEBでかんたん診療予約」
