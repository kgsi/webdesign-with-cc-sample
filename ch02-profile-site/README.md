# プロフィールページ（2-2節 導入演習用）

『Claude CodeではじめるWebデザイン入門』2-2節の導入演習で使う、1枚もののプロフィールページです。架空のグラフィックデザイナー「佐藤結衣」のページという設定です。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 演習の開始地点。内容は書けているが、見た目が整っていない状態 |
| `example-result/index.html` | 本文の演習（初回指示＋修正指示2回）を終えた状態の一例 |

## 使い方

1. `index.html` をブラウザで開いて現状を確認する
2. このフォルダをターミナルで開き、`claude` を起動する
3. 2-2節の指示を渡して、生成→ブラウザ確認→修正指示を一周する

AIの出力は同じ指示でも毎回変わります。手元の結果が `example-result` と違っていても問題ありません。
