# 共通プロンプト

Skillsあり・なしの両方で、次のプロンプトをそのまま使う。

```text
架空の会社のコーポレートサイトを、1枚のHTMLファイルで作ってください。

## 会社概要
- 社名：株式会社サンライズ製作所
- 事業内容：金属部品の精密加工（自動車・医療機器向け）
- 所在地：長野県松本市
- 創業：1974年
- 従業員数：48名

## ページ構成
以下のセクションを上から順に含めてください。
1. ヘッダー（ロゴテキスト＋ナビゲーション）
2. メインビジュアル（キャッチコピー：「0.001mmに、誠実を。」）
3. 私たちについて（3〜4文の会社紹介）
4. 事業内容（3つのサービスをカード形式で：精密切削加工／試作品製作／量産対応）
5. 会社情報（表形式で社名・所在地・創業年・従業員数）
6. お知らせ（ダミーの新着情報3件）
7. お問い合わせセクション（フォームは不要、メールアドレスの記載のみ）
8. フッター

## 条件
- HTML/CSS/JSはすべて1ファイルにまとめる
- 外部ライブラリやCDNは使わない
- 画像は使わず、CSSのみで表現する
- レスポンシブ対応する
```
