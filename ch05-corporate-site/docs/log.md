# 制作ログ

第5章の本文に載せる対話はこの記録から引く。プロンプトは実際に渡した文言、結果は観測した内容だけを書く。日付は 2026-09-11。

## 5-1 要件（docs/requirements.md）

ムードボードを読み、決まっていること（トーン、書体、グリッド、構成）と決まっていないこと（目的、読者、範囲、成功条件）を分けて `docs/requirements.md` に書いた。Claude Codeに要件を発明させず、著者が決めた。

## 5-2 情報設計（docs/sitemap.md、docs/wireframe.md）

- ナビ7項目の並びは取引先の関心順。トップ9セクションはムードボードの並びをそのまま採用し、理由を `sitemap.md` に残した
- ワイヤーフレームはFigmaで12カラムグリッド上に描き、`wireframe.md` にセクションごとの構造記述として書き起こした。Claude Codeには画像ではなく構造記述を渡す（カラム数や余白の数値が正確に伝わるため）

## 5-3 トーン（docs/tone.md、images/）

- ムードボードを6語、8色、5段階の書体、写真の条件に分解して `tone.md` に書いた
- 写真はUnsplashから7枚を選んだ。暖色のもの（夕景の風力発電）は候補から外した。出典は `README.md`

## 5-4 実装 v1（初稿）

### プロンプト（Claude Codeへ）

```
demo/corporate-site/ に架空企業のコーポレートサイトのトップページ index.html を作ってください。

- 要件は docs/requirements.md、ページの構造は docs/wireframe.md、色・書体・余白は docs/tone.md に書いてあります。3つを読んでから作ってください
- 静的HTML＋Tailwind CSS（CDN版）、JavaScriptは使わない。Noto Sans JPはGoogle Fontsで読み込む
- 写真は images/ にあるものを使う（hero.jpg, technology.jpg, about.jpg, business-datacenter.jpg, business-network.jpg, business-energy.jpg, sustainability.jpg）
- 会社名は NOVARC Inc.。ニュース記事やカードの文言は架空でよい
- 作るのは index.html 1ファイルだけ。docs や他のファイルは変更しない
```

### 結果（Claude Codeの報告から）

- 9セクションを構造記述どおりに実装。`tailwind.config` の `theme.colors` を8色で上書きし、定義外の色クラスが生成されないようにした
- プライマリボタンの塗りは白（文字 navy-950）。tone.md に「アクセントはボタンの塗りに使わない」とあり、ダーク面で navy-950 の塗りは見えないための判断
- レイアウト切替は `lg:`（1024px）。`md:`（768px）だとちょうど768pxでナビ7項目が溢れるため、768pxではハンバーガー表示にした
- TECHNOLOGYカードの面は navy-950＋slate-700 の枠線（構造記述に指定がなかった）。画像3枚は technology.jpg のトリミング違い

### ブラウザ確認（screenshots/v1-draft/）

headless Chromeで 375、768、1280 の3幅を撮影。375pxはheadless Chromeの最小幅（500px）より狭いため、375px幅のiframeに読み込んで撮影した。

観測したズレ：

| 分類 | 内容 |
|---|---|
| 構造 | カード右下の矢印が本文の直後に付いており、本文が2行と3行のカードで矢印の高さが揃わない（BUSINESSの2枚目） |
| 構造 | 375pxでH1「信頼を、デザインする。」が「る。」だけ2行目に落ちる |
| トーン | TECHNOLOGYの回路基板写真に銅色の暖色が入り、ダーク帯の中で浮く。3枚とも同じ写真で単調 |
| トーン | NEWSの「一覧を見る →」が文字の矢印で、カードのSVG矢印と形が揃っていない |
| 情報密度 | 問題なし。カードの本文は2〜3行、NEWSは4件で構造記述どおり |

想定していた「Tailwind標準のグレーが混ざる」「ナビが崩れる」は起きなかった。色は `theme.colors` の上書きで構造的に防がれ、ナビは1024px未満でハンバーガーに切り替わっていた。

## 5-4 改善 v2

### 修正指示（Claude Codeへ、同じセッションで）

```
ブラウザで375、768、1280の3幅を確認しました。次の4点を index.html で直してください。他は変えないでください。

構造
1. カードの右下の矢印が本文の直後に付いているので、本文が2行と3行のカードで矢印の高さが揃いません（BUSINESSの2枚目）。矢印をカードの下端に固定してください（TECHNOLOGYとBUSINESSの計6枚）
2. 375pxでH1「信頼を、デザインする。」が「る。」だけ2行目に落ちます。モバイルでは「信頼を、」で改行してください

トーン
3. TECHNOLOGYの回路基板写真に銅色の暖色が入り、ダーク帯の中で浮きます。写真に navy-900 系のオーバーレイを重ねてクールトーンに寄せてください。3枚とも同じ写真で単調なので、トリミングの違いをもっとはっきりさせるか、オーバーレイの濃さを揃えたまま画像の位置を変えてください
4. NEWSの「一覧を見る →」が文字の矢印で、カードのSVG矢印と形が揃っていません。カードと同じSVGの矢印アイコンに揃えてください
```

### 結果

- 矢印の `span` を `mt-6` から `mt-auto pt-6` に変更（カードは既に `flex flex-col` だった）
- H1の「信頼を、」を `<span class="block lg:inline">` で囲み、1023px以下で2行にした
- TECHNOLOGYの画像を `relative overflow-hidden` の枠で包み、`bg-navy-900/60` のオーバーレイを3枚同じ濃さで重ねた。トリミングは `object-[15%_30%] scale-125`、`object-center`、`object-[85%_70%] scale-150` で差を付けた
- NEWSのリンクを `inline-flex gap-2` ＋ 24pxのSVG矢印に変更

### ブラウザ確認（screenshots/v2-improved/）

4点とも一発で通った。375pxのH1は「信頼を、／デザインする。」の2行、BUSINESSの矢印3つは同じ高さ、TECHNOLOGYの銅色は抑えられた。

v2までで手作業で決めた事項（5-5でルールに昇格させるもの）：

- プライマリボタンはダーク面では白塗り、navy-950 文字。ライト面では navy-950 塗り、白文字（v2時点でライト面のプライマリは未使用）
- セカンダリボタンの枠線は、ライト面 slate-700、ダーク面 slate-200
- カードの矢印は `mt-auto` で下端固定。矢印は24pxのSVG、`stroke-width 1.5`
- テキストリンクは文字＋SVG矢印、`gap-2`
- 写真にオーバーレイを重ねるときは navy-950/60（ヒーロー）または navy-900/60（カード）
- レイアウトの切替は `lg:`（1024px）。768pxはモバイルレイアウト

## 5-5 デザインシステム（DESIGN.md、CLAUDE.md）

v2の実装から値とコンポーネントを抜き出し、`DESIGN.md`（人が読む仕様書）と `CLAUDE.md`（Claude Codeに読ませる制作ルール）に分けて書いた。役割の違い：

- `DESIGN.md`：色、文字、レイアウト、コンポーネント、セクションの型を、値とTailwindのクラスで書く。「何を使うか」
- `CLAUDE.md`：DESIGN.md を先に読むこと、使ってはいけないもの（定義外の色、`md:`、影、絵文字）、完了前の確認手順。「どう作業するか」

v2までに無かった決定で、DESIGN.md で新たに決めたもの：ライト面のプライマリボタン（navy-950 塗り）、Tagの選択中表示（`bg-accent text-white`）、下層ページの見出しの型（navy-950 背景）。

### news.html のプロンプト（新しいセッションで）

```
demo/corporate-site/ にニュース一覧ページ news.html を作ってください。

- まず同じディレクトリの CLAUDE.md と DESIGN.md を読み、そのルールに従ってください。既存の index.html も読み、ヘッダーとフッター、tailwind.config、フォント読み込みをそのまま再利用してください
- ページの構成は docs/sitemap.md の「ニュース一覧」の項：下層ページの見出し（英語ラベル NEWS ＋ H1「ニュース」）→ Tagの絞り込み風ラベル（すべて、お知らせ、IR、サステナビリティ、テクノロジー。「すべて」が選択中）→ 記事リスト10件（index.html の NEWS の4件を含む。日付は 2026年、内容は架空）→ ページネーション（1、2、3、次へ）→ フッター
- 記事リストの行は index.html の NEWS の行と同じマークアップにする
- ナビの「ニュース」は現在ページの表示にする
- 作るのは news.html 1ファイルだけ。index.html、docs、DESIGN.md、CLAUDE.md は変更しない
- 完了したら、ファイルのパスと、CLAUDE.md の「完了前の確認」の結果、判断した点を3〜5行で報告してください
```

### 結果（news.html、v3）

サブエージェントの報告：`news.html` を1ファイル作成。ヘッダーとフッターは `index.html` からコピーし、ナビのリンク先を `index.html#about` 等に、ロゴを `index.html` に変更。「ニュース」に `text-white` と `aria-current="page"`。Tag は「すべて」を `bg-accent text-white` で選択中に。ページネーションは DESIGN.md に定義が無かったので、テキストリンクと Caption の組み合わせだけで作り、DESIGN.md に項を追加することを提案。色は8色内、`md:`・`sm:`・`shadow` は0件。

ブラウザ確認（screenshots/v3-final/）：ヘッダー、Tag、リスト行の余白と罫線、フッターはトップと同じに見える。375px ではリスト行が日付＋Tag／タイトルの2段に折れ、トップの NEWS と同じ挙動。修正指示は出さなかった。

ルールに無いものをどう埋めたか：ページネーションは既存部品の組み合わせで作られた。定義が無い部品を新しく発明せず、あるものを組み合わせる方向に倒れたのは CLAUDE.md の「定義外のものを使わない」が効いた結果とみる。提案どおり DESIGN.md に「ページネーション」の項を追加した。

## 5-6 公開前チェック

`docs/checklist.md` の9項目を Claude Code に実行させ、結果を同ファイルに記録した。要点：

- 横スクロール、リンク、alt、フォント、素材の出典、色の逸脱は問題なし
- コントラスト比：`slate-500` の Caption がダーク面（navy-950 で 3.9:1、navy-900 で 3.7:1、teal-900 で 2.7:1）と slate-200 の上（3.9:1）で AA 未満。ダーク面は `slate-200/70`（6.0〜7.8:1）、slate-200 の上は `slate-700`（8.4:1）に変更し、DESIGN.md の色の表と CLAUDE.md に「Caption の色は面で変える」を追記した。5-5 で作ったルールに穴があり、チェックで見つかってルールに戻す流れになった
- OGP と favicon は未実装だったので追加した。`og:image` は相対パスのまま（公開URLが決まってから絶対URLにする）。タグの有無は grep で確認しただけで、SNS のプレビューやタブのアイコンは未確認
