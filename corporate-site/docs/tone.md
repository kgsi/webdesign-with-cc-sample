# トーン設計メモ

5-3の成果物。ムードボード（`../moodboard.png`）を言葉と数値に分解したもの。Claude Codeへのプロンプトではこのファイルを参照させる。

## キーワード（6語）

信頼、先進性、ミニマル、クール、知性、グローバル

- 信頼、知性：色数を絞り、余白を広く取る。装飾で盛らない
- 先進性、クール：ダークトーンを基調にし、青のアクセントを1色だけ使う
- ミニマル：罫線は細く、角丸は小さく、影は使わない
- グローバル：英語の小ラベルと日本語の見出しを組み合わせる

## 色（8色）

ムードボードに明記された8色。この8色以外は使わない。Tailwind標準の `gray`、`zinc`、`neutral` や、定義していない `slate` の段階（slate-100、slate-400 など）を混ぜない。

| 名前 | HEX | 役割 |
|---|---|---|
| navy-950 | #0B1320 | ベース背景（ヘッダー、ヒーローのオーバーレイ、フッター） |
| navy-900 | #111B27 | セカンダリ背景（TECHNOLOGY帯）、ライト面の本文テキスト |
| teal-900 | #1F3537 | 差し色の帯（INVESTOR RELATIONS） |
| slate-700 | #334155 | 罫線、セカンダリボタンの枠 |
| slate-500 | #64748B | キャプション、日付、英語ラベル |
| slate-200 | #E2E8F0 | ダーク面の本文テキスト、ライト面のセカンダリ背景（BUSINESS）、ライト面の罫線 |
| white | #FFFFFF | 見出し（ダーク面）、ライト面の背景、カードの面 |
| accent | #2563EB | テキストリンク、カードの矢印、アクティブ状態、Tag |

- ダーク面の見出しは白、本文は slate-200。ライト面の見出しと本文は navy-900
- アクセントは面積を小さく。ボタンの塗りには使わず、リンクと矢印とTagに限る

## 書体（5段階）

Noto Sans JP（Google Fonts）。ウェイトは 400、500、700 の3つ。

| 用途 | サイズ/行送り | ウェイト |
|---|---|---|
| H1 | 40px / 56px | 700 |
| H2 | 28px / 40px | 700 |
| H3 | 20px / 32px | 500 |
| Body | 16px / 28px | 400 |
| Caption | 12px / 20px | 400 |

- セクションの英語ラベル（NEWS、ABOUT US など）は Caption サイズ、字間 0.2em、大文字、slate-500
- モバイルでは H1 を 32px / 44px、H2 を 24px / 36px に落とす

## グリッドと余白

- 12カラム、コンテナ 1280px、左右マージン 80px（モバイル 24px）、ガター 24px
- セクションの縦余白は 96px（モバイル 64px）。詰めない
- 罫線は 1px。ダーク面は slate-700、ライト面は slate-200

## 写真の条件

- クールトーン。青〜グレーに寄せ、暖色（夕景、木目、肌色が主役のもの）を避ける
- 高コントラスト。ダークオーバーレイを重ねて白文字が読める明度にする
- 余白を活かした構図。被写体を中央に詰めない
- 題材：ガラス建築、回路基板、データセンター、山霧、風力発電
- 出典はUnsplash。ファイルと撮影者の一覧は `../README.md`

## 参考サイトの観察メモ

実在サイトの名前とスクリーンショットは残さない。3観点で観察した内容だけを書く。

| 観点 | 観察 | このサイトへの適用 |
|---|---|---|
| 構造 | 上場テック企業のトップは、ヒーロー直下にニュースを置き、事業・技術・サステナビリティ・IRの順で流すものが多い | ムードボードの9セクションと一致。並びは変えない |
| トーン | ダーク基調のサイトは、写真にオーバーレイを重ねて白文字を載せ、アクセントは1色に絞っている。灰色の段階が多いと安っぽく見える | 8色以外を使わない。オーバーレイは navy-950 の 60% |
